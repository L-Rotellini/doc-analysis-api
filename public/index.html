# Document Statut Créée Analysée

Aucune demande pour l'instant.

Comment ça marche ?
  1. Le formulaire appelle POST /requests. AdonisJS insère la demande en base via Kysely (status: pending).
  2. L'API dépose un job BullMQ dans Redis et répond 202 Accepted tout de suite.
  3. Un worker séparé (node ace worker:start) consomme le job, simule l'analyse (2 s), puis met à jour la ligne en status: analyzed.
  4. Cette page interroge GET /requests chaque seconde pour montrer le basculement en direct.
